**PodStudio for Windows**, rewritten in C++: a 15 MB installer with no Python or GTK. It opens the same session folders as the Linux app.

Unofficial. Not affiliated with RØDE. Works with the PodMic USB only.

## Install

Download **`PodStudio-<version>-x64-setup.exe`** and run it. It installs for your user (no admin prompt), upgrades over the earlier Python build, and leaves your sessions in `Music\PodStudio` alone.

The installer is unsigned, so Windows will warn: choose **More info**, then **Run anyway**. The portable `.zip` needs no install. Each file has a `.sha256`.
