# Podstudio: handoff for Claude Code

## Overview
Podstudio is a single-tenant podcast studio running on Tyler's **home/local server**, behind Caddy, with S3-compatible storage. The eventual product records solo/remote sessions, edits audio and video, transcribes, clips, exports and hosts RSS. The first usable release is the **desktop solo-audio workflow through Stage 06**, including import of an existing show, retake cleanup, voice processing, noise reduction and password-protected listening links. Remote guests, transcription/AI, the full public site/embeds, video, editor-project interchange and the mobile host app come later. See `BUILD_PLAN.md` for the confirmed decisions and technical contracts.

### Release and stage boundaries
- PREBUILD must prove dependency compatibility, persistent recording recovery, 2-hour/8-track performance and DSP/render consistency before Foundation.
- Stages 00–06 deliver Release 1: solo recording, durable recovery, multitrack editing, annotation **and recorded tone** on K, required noise reduction/voice FX, WAV/MP3 export, existing-feed import, validated publication and password-protected listening.
- Stage 07 adds remote transcription/LLM services and sentence-aware retake refinement. Stage 08 supports up to 4 total participants (including the host) with optional live video. Stage 09 adds the full SSR public site and embeds.
- Stage 10 is split into 10a ingest/sync/basic MP4, 10b shots/branding, 10c clips/audiograms and 10d editor-project interchange. Final Cut Pro, Premiere Pro and Resolve are all planned, after finished-media export, one editor per review checkpoint.
- Stage 12 mobile recording is deferred. Browser viewport checks do not establish real-device capture/background support.
- `STATUS.md` is the execution queue. Only work on the current stage; stop for review at its end.

### Podcast hosting (optional module)
**Feed audio: MP3 only (14, show settings)**: hosted audio enclosures are MP3 (`audio/mpeg`), 44.1 kHz, CBR, normalized to −16 LUFS stereo / −19 mono within ±0.5 LU, with a PREBUILD-approved true-peak ceiling verified after encoding. ID3v2 includes title, artwork and CHAP/CTOC chapters. Transcode WAV/FLAC/AIFF/M4A inputs with ffmpeg/libmp3lame and retain originals privately; reject non-MP3 hosted audio enclosures. Presets: **64 kbps mono speech**, **96 kbps stereo speech**, **128 kbps stereo speech + music (default)**, **192 kbps stereo music-heavy**. Show file-size estimates. WAV is an export/private source, not a public feed alternate. Video MP4 is a later alternate enclosure. Existing-feed import inventories non-MP3 archives for explicit review/conversion before cutover; do not silently replace historical media or change identities.

**16b Lock & verify**: **Feed lock**: writes `<podcast:locked owner="{email}">yes|no</podcast:locked>`, locked by default for new and imported shows. The owner email must be verified. **17b Move podcast (feed redirect)**: Stage 11 validates the destination RSS, identical show/episode GUIDs and episode inventory before enabling a redirect. ## GUID rules (non-negotiable)
Podcast apps use GUIDs to tell episodes apart. Changing one makes every subscriber see the episode as new, and they download it again.
- **On import:** preserve the GUID character value exactly without trimming, case changes or regeneration, and preserve whether `isPermaLink` is absent, true or false. Store both as immutable fields; retain the source feed as audit evidence. XML escaping may differ without changing the value; never interpret reserialization as permission to normalize identifiers. Keep imported show `podcast:guid` and namespace metadata. Flag missing/duplicate item GUIDs for review instead of inventing replacements. Chapters/transcript URLs may change without changing item identities.
- **New episodes created in Podstudio:** generate a UUID v4 when the episode is first created, before the first publish. Never derive it from title, URL, slug or date. It must not change when the title, slug, audio file or feed domain changes, or after re-publishing, unpublishing and publishing again, or a move.
- **Uniqueness:** enforce a unique index on (show_id, guid). The importer must reject a feed containing duplicate GUIDs and show which items collide. It must not auto-fix them.
- **Show GUID:** preserve an imported `podcast:guid`. For a new show, UUID v5 uses namespace `ead4c236-bf58-58c6-a2c6-a6b28d128cb6` and the canonical feed URL with the protocol scheme and trailing slashes removed. Generate once at creation and never recompute after a URL change. If an imported feed lacks the tag, resolve its existing Podcast Index identity if available; report the proposed identity/seed for owner review before assigning one. Do not silently derive it from the new hosting URL.
- **Moving away (17b):** the new feed must keep the same GUIDs. The validator already blocks the redirect if they don't match.
- Tests: import a feed, re-export it, and diff all GUIDs (must be identical). Edit every episode field and confirm the GUID is unchanged.
