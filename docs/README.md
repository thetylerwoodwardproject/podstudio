## Layout

Every project in this family keeps its docs the same way:

```
docs/
  README.md      this index
  SPEC.md        the product spec (where one exists)
  ROADMAP.md     Platforms line, then Now / Next / Later / Done
  mockup/        shadcn/ui mockup: same project shape in every repo
  images/        logos and screenshots used by the README (where used)
```
